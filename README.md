# dotsync

Barebones shell sync repo.

## Source of truth
- `bin/` -> deploys to `~/.local/bin/`
- `.bash_aliases` -> deploys to `~/.bash_aliases`

Current post shortcuts after sync:
- `gp` -> `gen-posts`
- `fp` -> `finalize-posts`

Current subtitle shortcuts after sync:
- `csub` -> `clean-subs`
- `fs` -> `finalize-subs`

## Deploy
```sh
~/shell/dotsync/dotsync.sh
```

Or use the deployed command:
```sh
d
```
